# SecurityTimeCamera website

Static product landing page for **SecurityTimeCamera v3.9**.

- Public website: https://aentongthi.github.io/security-time/
- Published branch: `website`
- Android release: [SecurityTimeCamera v3.9](https://github.com/aentongthi/security-time/releases/tag/v3.9)
- Direct APK: https://github.com/aentongthi/security-time/releases/download/v3.9/app-debug.apk
- Supported Android version stated by the release: Android 8.0 or newer.
- APK size: approximately 10.3 MB.

## Website contents

- Responsive landing page with mobile navigation.
- Product overview and actual application screenshots.
- Trial and paid-plan information.
- VietQR payment display, account/content copy helpers, and Zalo support link.
- Installation guide, FAQ, release notes, and usage transparency notice.

## Plans and activation

- Trial: up to 1 day, subject to activation availability on the device.
- 15 days: 30,000 VND.
- 30 days: 60,000 VND.

**Payment and license activation are manual.** The website displays a QR code and helps the customer send the transfer details to the administrator. It does not verify bank transactions, issue license keys, or activate devices automatically. The administrator checks the payment and device code, then provides the key through Zalo.

## Verification wording

The app's LIVE, CUSTOM, and GALLERY labels are internal app-level status checks. A manually selected display time or an image imported from the gallery must not be presented as a live capture. These labels are not an independent third-party or government certification.

## Hosting

The site is static HTML/CSS/JavaScript and is published with GitHub Pages from the `website` branch. There is currently no website backend or payment webhook. No bank credentials, API secrets, or license keys should be placed in the public repository.
